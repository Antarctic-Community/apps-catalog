# Как добавить приложение

1. Форкните репозиторий.
2. Создайте папку `apps/<id>/` (`id` — латиница, цифры и дефисы, например `my-app`):
   ```
   apps/my-app/
   ├── app.json
   ├── icon.png            # квадрат, ≥ 256×256, ≤ 300 КБ
   └── screenshots/
       ├── 1.png           # ≥ 600 px по короткой стороне, ≤ 1.5 МБ, до 8 шт.
       └── 2.png
   ```
3. Заполните `app.json` (`awAppId` — числовой id из ссылки `https://aw.me/app/<awAppId>`) (формат — `schema/app.schema.json`, пример — `apps/remix-app/app.json`).
4. Проверьте локально: `npm ci && npm run validate`.
5. Откройте PR. CI проверит схему и картинки, модераторы — содержимое.

## Что проверяют модераторы
- приложение работает, открывается по HTTPS, не ломается внутри кошелька;
- описание и скриншоты честные, нет обмана и вводящих в заблуждение обещаний;
- не копирует чужой бренд, нет вредоносного поведения;
- категория выбрана верно.

## Чего в PR быть не должно
`collections.json` («Популярные», баннер) — зона мейнтейнеров.
«Новые» — 20 приложений с самой поздней датой создания. «Топ приложений» — пять с наибольшим MAU. «Проверенные нами» и значок — приложения с `isVerified: true`. Всё это запрашивается при сборке: `GET /api/v2/apps/<awAppId>` (`createdAt`, `mau`, `isVerified`).

## Локальная разработка
```
npm ci
npm run dev       # http://localhost:5173
npm run build     # dist/ — то, что публикуется на GitHub Pages
```
Готовый каталог в виде JSON доступен по `<site>/data/catalog.json`.
